# Minimal TEI V2 to Ekdosis fixtures

These fixtures document the TEI currently produced by Ekdosis-TEI Studio and the minimal LaTeX-Ekdosis output expected from a future TEI-to-Ekdosis converter.

`input.xml` files are generated from `source.txt` and `config.json` with the current project pipeline. `expected.tex` is intentionally a minimal Ekdosis fragment, not a final PURH layout.
