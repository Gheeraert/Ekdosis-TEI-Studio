Importations de configurations antérieures

La configuration JSON permet seulement de restaurer les champs textuels, les options et la structure du formulaire ; les fichiers devront être sélectionnés de nouveau pour être importés.

Restaure la configuration complète à partir d'un ZIP préalablement généré.

Métadonnées générales
Fichiers généraux

Les fichiers DOCX sont acceptés pour la page d'accueil, l'introduction, les notices et les préfaces. Les pièces dramatiques doivent être en XML.

Corpus de pièces

Chaque pièce doit être fournie sous forme d'un XML dramatique complet. Les notices et préfaces peuvent être fournies en DOCX ou en XML. Le dramatis personae, s'il est fourni séparément, doit être en XML.
