Cet outil génère un site statique complet à partir d'une page d'accueil, d'une introduction générale, d'un corpus de pièces XML-TEI et de leurs paratextes (notices et préfaces en DOCX ou XML).

Version 1 — limitations actuelles : cette version accepte une seule pièce à la fois. La génération de PDF, la publication FTP et le mode back/privilège ne sont pas disponibles dans cette interface web.

Configuration du constructeur

Pour des raisons de sécurité, le navigateur ne peut pas réimporter automatiquement les fichiers locaux. La configuration JSON permet de restaurer les champs textuels, les options et la structure du formulaire ; les fichiers devront être sélectionnés de nouveau.

Le paquet source ZIP contient la configuration et les fichiers sources. Il peut être réimporté directement dans l'outil « Publication ZIP ».

Métadonnées générales
Fichiers généraux

Les fichiers DOCX sont acceptés pour la page d'accueil, l'introduction, les notices et les préfaces. Les pièces dramatiques doivent être en XML.
