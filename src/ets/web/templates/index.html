{# ── Onglet 7 : Protocole de transcription ── #}

Protocole de transcription ETS

Aide-mémoire des marqueurs principaux. Les sections ci-dessous développent chaque point.

MarqueurRôle
####…####Acte
###…###Scène
##…##Personnages présents dans la scène
#…#Locuteur
#####Ligne entièrement réécrite ou lacune
***Coupe dans un vers partagé
**…**Didascalie explicite
$$TYPE$$…$$fin$$Didascalie implicite
%%strophe…%% / %%fin_strophe%%Bloc lyrique
%%castlist%% / %%fin_castlist%%Dramatis personae
Structure dramatique

La transcription reproduit la hiérarchie dramatique au moyen de marqueurs encadrés.

  • ####ACTE I#### — ouvre un acte.
  • ###SCENE I### — ouvre une scène.
  • ##ORESTE, PYLADE## — liste les personnages présents dans la scène.
  • #ORESTE# (ou #ORESTE.#) — indique le locuteur.

Chacun de ces blocs contient autant de lignes qu'il y a de témoins dans la configuration. Les lignes sont dans l'ordre des témoins déclarés.

Variantes, lacunes et lignes entièrement réécrites

Les variantes ordinaires (graphiques, lexicales) sont calculées automatiquement à partir des différences entre les lignes de chaque témoin : il n'y a rien à marquer.

Quand une ligne est entièrement différente d'un témoin à l'autre — au point qu'aucun mot n'est commun — on la précède du marqueur #####. Quand un témoin ne contient pas du tout la ligne, on utilise ##### (lacune).

Exemple avec trois témoins, dont le troisième a réécrit la ligne :

##### Accordez quelque trêve à ma douleur amère,
##### Accordez quelque trêve à ma douleur amère,
##### Accordez cette grâce aux larmes d'une mère.
Vers partagés

Lorsqu'un vers métrique est réparti entre plusieurs locuteurs, on segmente les répliques avec le marqueur *** : la première partie se termine par ***, la suivante commence par ***.

Exemple :

#HERMIONE#
#HERMIONE#

Vous partez ?***
Vous partez ?***

#ORESTE#
#ORESTE#

***Je pars.
***Je pars.
Didascalies

Didascalies explicites (présentes dans le texte imprimé) : encadrées par **…**, par exemple **Il sort.**

Didascalies implicites (reconstruites par l'éditeur) : encadrées par $$TYPE$$…$$fin$$.

Types disponibles :

CodeSignification
SPCParole (modalité d'élocution)
ASPAspect (apparence, costume)
TMPTemps
EVTÉvénement
SETDécor
PROXProxémie (déplacements, positions)
ATTAttitude (geste, posture)
VOIVoix (ton, registre vocal)

Exemple : $$ATT$$ Il s'agenouille. $$fin$$

Chœurs

Les chœurs sont traités comme des locuteurs collectifs ordinaires. On utilise le marqueur habituel du locuteur, par exemple #CHOEUR#, #CHŒUR# ou #LE CHŒUR#.

Les graphies propres à chaque témoin doivent être conservées telles quelles, sans normalisation.

Strophes et métrique

Dans le cours ordinaire de la tragédie, l'alexandrin n'est pas marqué. Dans les passages lyriques (strophes, odes), chaque vers porte une indication métrique explicite : =12= pour un alexandrin, =10= pour un décasyllabe, etc.

Une strophe est délimitée par %%strophe …%% et %%fin_strophe%% :

%%strophe subtype=distique rhyme=aa%%
=12=Premier vers lyrique
=10=Second vers lyrique
%%fin_strophe%%

Dans une variante de ligne entière à l'intérieur d'une strophe, le marqueur ##### précède l'indication métrique :

#####=12=Un vers entièrement réécrit
#####=12=(lacune)
Dramatis personae / castlist

Le dramatis personae est saisi dans un fichier séparé (ou dans le champ Dramatis personae de l'onglet Saisie). Il commence par %%castlist%% et se termine par %%fin_castlist%%.

Chaque entrée de personnage utilise :

%%cast id=oreste role="Oreste" desc="Fils d'Agamemnon" aliases="ORESTE"%%
  • id — identifiant stable (minuscules, sans espaces).
  • role — forme régularisée du nom (affichée dans la sortie).
  • desc — courte description du personnage.
  • aliases — formes reconnues dans le texte transcrit.
