À propos d'Ekdosis-TEI Studio

Ekdosis-TEI Studio est une plate-forme de saisie, d'encodage, de validation, de visualisation et de publication pour l'édition critique du théâtre classique.

Elle permet de travailler à partir d'une transcription structurée légère, proche d'un pseudo-markdown, afin de produire une TEI régulière, réutilisable et publiable.

Fonctions principales

  • Édition critique de textes de théâtre transmis par plusieurs témoins, avec gestion des variantes.
  • Génération de sites statiques destinés à la consultation et à la publication.

Crédits

Ekdosis-TEI Studio a été réalisé par Tony Gheeraert dans le cadre de la chaire d'excellence en édition numérique portée par Marcello Vitali-Rosati, avec l'aide de Clara Matos.

Ekdosis est un package LaTeX développé par Robert Alessi pour la composition d'éditions critiques et d'apparats savants.

Fonctionnement

Le principe d'ETS est de séparer la saisie, la validation et la publication. L'utilisateur saisit ou importe une transcription ETS ; le validateur signale les erreurs éventuelles ; le logiciel produit ensuite un XML-TEI canonique, un aperçu HTML, du LaTeX/Ekdosis et, selon les cas, un site statique publiable. Le programme est destiné à des éditeurs sans compétences particulières en humanités numériques : la génération du XML, du LaTeX et de l'HTML est entièrement automatique à partir de la transcription.

La présente interface web reprend les fonctions essentielles d'Ekdosis-TEI Studio pour la saisie, la validation, la génération TEI, l'aperçu HTML et l'export. Le programme original en Python comporte des fonctionnalités supplémentaires, notamment pour le travail éditorial avancé et l'usage local.

Le code source du projet est disponible sur GitHub : github.com/Gheeraert/Ekdosis-TEI-Studio.
