# Module Références

Dernière mise à jour documentaire : 5 juin 2026.

## 1. Objet

Le module Références aide à gérer des références bibliographiques et des citations dans les péritextes, notices et commentaires.

## 2. Fonctions visées

Le module peut permettre :

- ajout manuel d’une référence ;
- import de références ;
- insertion de citation ;
- génération d’une bibliographie ;
- choix d’un style simple.

## 3. Relation avec TEI

Les références doivent pouvoir être représentées dans la TEI ou associées à elle.

Leur rendu HTML et LaTeX doit rester dérivé de la donnée structurée.

## 4. Relation avec LaTeX

Les bibliographies des péritextes relèvent du LaTeX standard.

Ne pas les faire passer par Ekdosis sauf nécessité particulière liée au texte critique.

## 5. Prudence

Le module Références ne doit pas devenir un logiciel bibliographique complet.
Il doit fournir les fonctions nécessaires à la chaîne ETS/PURH.
